# Lemiex Operations Console

Frontend React + TypeScript cho hệ thống Feline AI, lấy cảm hứng bố cục từ FreeDash Lite nhưng được thiết kế lại cho dữ liệu vận hành Lemiex.

## Chạy phát triển

```bash
pnpm install
pnpm dev
```

Vite proxy `/api` sang `http://127.0.0.1:3000`.

## Chạy cùng hệ thống

```bash
docker compose up --build -d
```

Mở `http://127.0.0.1:8080` trên máy Windows.
